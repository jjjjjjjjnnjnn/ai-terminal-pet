# docs/assets

Screenshots and the hero banner are generated by `render_assets.py` from the
real Win32 rasterizer (`go test ./internal/ui -run TestRenderPreview` and
`-run TestRenderSettingsPreview`), so they can never drift from the shipped
layout. Nothing here is hand-drawn or mocked up.

| File | Size | Used in | What it shows |
|---|---|---|---|
| `hero.png` | 1600x640 | README top | Gradient banner with the three-line pitch and the compact/expanded panels side by side |
| `overlay-compact.png` | 168x468 | README, *What it looks like* | Compact strip with the pulsing orb, session count and the waiting project name |
| `overlay-expanded.png` | 400x424 | README, *What it looks like* | Expanded list with three sessions (project, state, source, relative time) |
| `overlay-expanded-many.png` | 400x676 | README, *What it looks like* | Six rows plus the overflow line, from the `6 rows + more` layout test |
| `overlay-auto-approve.png` | 400x424 | README, *What it looks like* | Auto-approve countdown with the draining bar and `Allow (5s)` |
| `overlay-compact-en.png` | 168x468 | not referenced | Same compact strip under the English locale, kept for localization checks |
| `overlay-compact-hover.png` | 168x468 | not referenced | Compact strip in the hovered state (raised background and stroke) |
| `overlay-expanded-en.png` | 400x424 | not referenced | Expanded list under the English locale, kept for localization checks |

The three `-en` / `-hover` variants are not linked from the README because the
Chinese captures already carry the same geometry; they exist so a locale or
hover regression is visible without running a window.

Regenerate everything:

```powershell
$env:PET_PREVIEW_DIR = "$env:TEMP\petpreview"
go test ./internal/ui -run TestRenderPreview
go test ./internal/ui -run TestRenderSettingsPreview
python docs/assets/render_assets.py
```

`render_assets.py` reads the rasterizer output from `PET_PREVIEW_DIR`, trims the
flat background, and writes all PNGs listed above. The settings-window previews
are written to `$env:TEMP\petpreview-settings` and are not published here.
